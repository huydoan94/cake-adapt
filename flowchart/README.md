# cake-adapt current-code flowcharts

Open **index.html** in a browser. It is an offline viewer containing 16 linked diagrams.

- Standalone vector images: `diagrams/*.svg`
- Editable Graphviz sources: `diagrams/*.dot`
- Structured graph data: `flowchart-data.json`
- Source snapshot and SHA-256 hashes: `source-manifest.json`

The diagrams document the implementation at commit `69a67a9`. They do not claim that the discussed 5 Mbps reserve/capacity-learning policy is implemented.
