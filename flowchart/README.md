# cake-adapt current-code flowcharts

[View the rendered flowchart viewer](https://raw.githack.com/huydoan94/cake-adapt/main/flowchart/index.html),
or open `index.html` locally. The viewer contains 16 linked diagrams and works
without a build step.

The hosted link reads the `main` branch and therefore reflects the latest
version pushed to GitHub.

- Standalone vector images: `diagrams/*.svg`
- Editable Graphviz sources: `diagrams/*.dot`
- Structured graph data: `flowchart-data.json`
- Source snapshot and SHA-256 hashes: `source-manifest.json`

The diagrams document the current working-tree implementation based on commit `f8c615e`. They do not claim that the discussed 5 Mbps reserve/capacity-learning policy is implemented.
