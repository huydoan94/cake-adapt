cake-adapt, 2026-10-27: the restructure toward 1.0 against 0.3.30

OpenWrt 25.12 x86 VM clone: the restructured tree (built as 0.3.30-r1) against 0.3.30 before it. The method and conclusions are in README.md. The comparison graphs are the 2026-10-22 run's, of the same code as 0.3.30.

The perf pass ran while an OpenWrt image build loaded the host, so its sample counts are not comparable with earlier runs; the shares within each graph are. Hover over frames for values and click frames to zoom.
